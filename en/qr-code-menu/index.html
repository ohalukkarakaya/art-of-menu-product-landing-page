In short

A QR code menu is a digital version of your menu that guests open by scanning a code on the table, without downloading an app. ArtOfMenu builds one from the PDF you already have, opens it in each guest's phone language with photos and allergen details, and lets you change items and prices at any time while the printed code stays the same.

How a contactless menu works at the table

A guest sits down at table 4, points the phone camera at the code on the stand and taps the link. The menu opens in the browser, in the language the phone is set to. They look at the photos, check the allergens and decide.

You keep the printed code. When the price of a flat white goes up or the soup of the day sells out, you edit the menu, and the next guest who scans sees the new version. The code on the table never needs reprinting.

Who it is for

ArtOfMenu is made for cafés, restaurants, bars and bakeries, from a single counter to a group of branches. A bakery can use it to show this morning's bread with allergens. A restaurant near the old town can use it so tourists read the menu without a translation app.

Beyond the menu: ordering and smart features

When you want more than a menu, the Order plan lets guests send orders from the table straight to the waiter's phone. The Smart plan goes further. It moves hot drinks up when the weather turns cold, suggests what goes well with each item and sets tomorrow's prices inside limits you choose.

Privacy guests can trust

The menu does not use cookies, persistent IDs or stored IP addresses for guests, and the statistics you see are anonymous. Your prices are never shared with other businesses. If you decide to stop, you cancel in one step and keep using the menu until the paid period ends.

Frequently asked questions

What is a QR code menu?

It is a menu guests open on their own phone by scanning a printed code at the table. The code links to a web page with your items, prices, photos and allergens. Because the page is online, you can change it at any time without reprinting anything.

Do guests need to download an app?

No. The phone camera reads the code and opens the menu in the browser. ArtOfMenu then shows it in the language the phone is set to, so most guests never need to look for a language option.

Are QR code menus still worth it?

Some guests prefer paper, and keeping a few printed copies at the counter is a fair courtesy. A QR menu earns its place when you change prices or dishes often, serve visitors who read other languages or want guests to order from the table without waiting.

Can I use my current PDF menu?

Yes. On every ArtOfMenu plan you can upload the PDF menu you already have and go live the same day. You can add photos and allergen details item by item afterwards, while the menu is already working.
